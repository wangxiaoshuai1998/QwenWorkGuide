# 实战指南｜内容创作者从选题到复盘全流程



本次我们将内容运营的全流程拆分为了6个环节，教你如何用AI 快速把内容生成变成一条顺畅的流水线，你可以直接跳转到自己最关注的部分。

| **对应环节** | **你的核心需求** |
|----------------|----------------------|
| **环节① 情报输入** | 快速盯行业热点、拆解爆款，找到能跟的选题 |
| **环节② 选题决策** | 把零散情报沉淀成选题库，定优先级与发布排期 |
| **环节③ 内容生产** | 把选题快速做成可拍可发的脚本与文案 |
| **环节④ 多平台适配** | 一稿多发、按平台调性改写，甚至出海本地化 |
| **环节⑤ 物料封装** | 批量生成图文、海报文案、短视频混剪脚本等物料 |
| **环节⑥ 数据复盘** | 聚合多平台数据、复盘表现，反哺下一轮选题 |

千问办公 的价值，就是帮你**把这些环节串起来**：它能直接读写你的本地文件、联网把资料抓回来、调用各种专业 Skill、把每一步的产出落成下一步能直接用的文件。

你不再是每个环节单独求助一次AI对话助手，而是让AI沿着流水线把活一段段接着干完。

按照这个指南，一个人也能轻松运营自媒体。

# 环节① 情报输入：盯热点 \+ 拆爆款
>    

**在流水线中的位置：输入＝你的行业 / 对标账号 ｜ 输出＝每日热点简报 \+ 可复用的爆款公式**，喂给环节②做选题。

这是整条流水线的源头。

做内容不能闭门造车，得先知道“行业在发生什么” 和 “什么内容正在火”。

这一步要做两件事：
- 联网把行业热点扒回来、按重要性排好、每条带来源
- 把跑出来的爆款逐条拆解，反推出可复用的公式。把链接和素材丢给 千问办公，它能批量读、找共性、产出能直接转发的简报和能直接套用的公式。

**推荐的工作流是：**
1. 指定行业 \+ 对标账号 / 爆款链接
2. 让它联网搜集热点、按重要性排序标来源
3. 同时拆解对标爆款的钩子 / 结构 / 情绪
4. 输出“热点简报 \+ 爆款公式”两份文件，沉淀备用。

## 实战 Prompt

### 每日行业热点简报（最常用模板）
```text
搜索今日【你的行业】的热点新闻，覆盖：
1) 重要产品发布或功能更新
2) 融资事件与行业并购
3) 政策法规/平台新规变动
4) 爆款动向与市场趋势。

输出要求：按重要性排序列 5-8 条，每条含「标题 + 一句话摘要 + 来源链接」，最后附一段 2-3 句的"今日趋势点评"。保存为 Markdown 文件，文件名带日期。

```

### 拆解一批爆款、提炼公式
```text
这是我们/对标账号近 30 天的【8 条爆款视频链接或已导出文案】。
请逐条拆解「前 3 秒钩子、内容结构、情绪触发点、结尾互动设计」，再归纳出 3 条可复用、可放大的爆款公式。整理成文档保存，供后续选题使用。

```

### 盯单一竞品 / 品牌的动态
```text
搜集【目标品牌】近 24 小时的市场营销相关消息，包括产品营销、品牌营销、渠道动作、用户活动、竞争动态。对重要动作做简要分析，输出保存为 Markdown。

```

3. **一次性给 AI 多条同类爆款，它才可以拆得出“共性”而非单条内容的点评**

# 环节② 选题决策：把情报变成选题库与排期
>    

**在流水线中的位置：输入＝环节①的热点简报 \+ 爆款公式 ｜ 输出＝选题表 \+ 内容排期**，喂给环节③做生产。

在这个环节需要做2件事情：
- 把零散的热点和爆款公式，转化成符合账号定位、受众需求的具体选题
- 按优先级和发布节奏排好计划，让内容生产从“临时想题”变成“按表推进”

把环节 ① 的产出、账号定位和目标受众交给 千问办公，它能批量生成带钩子的选题，标注对应的爆款公式和受众需求，再整理成可长期复用的选题库与周/月排期。

**推荐的工作流是：**
1. 提供热点简报、爆款公式，以及账号定位和目标受众
2. 按公式批量生成选题，并为每个选题补充钩子和内容角度
3. 根据时效性、受众匹配度和制作成本确定优先级
4. 输出“选题库 \+ 周/月排期”两份文件，交给环节③逐条生产

## 实战 Prompt

### 按爆款公式批量生产选题
```text
读取附件的爆款公式文档，结合我的账号定位【赛道 + 受众】，按公式给我 15 个有爆款潜质的新选题，每个选题配一句话钩子，并标注它对应哪条公式、预期能戳中受众什么需求。整理成表格保存。

```

### 一个月内容排期
```text
我的公司是【公司 + 主营业务】，目标人群【人群】。
请基于附件选题做一个月的【公众号/短视频】内容排期：按周排布、每条标注角度、目标和建议发布日，有不清楚的地方先反问我，确认后再定稿成排期表。

```

### 起号期选题方向
```text
【某角色/老板】想做个人 IP 推广【产品】。请给出最快起流量的 10 个选题方向，并排出一份可执行的 30 天运营计划（按周排期、标注每周内容重点与目标）。

```

# 环节③ 内容生产：把选题做成脚本与文案
>    

**在流水线中的位置：输入＝环节②的选题表 \+ 排期 ｜ 输出＝口播脚本 / 初稿文案**，喂给环节④做多平台适配。

选题定了，进入生产车间：把一个选题变成能拍、能发的脚本或初稿。

这一步最看重“可执行”：口播要能直接念，脚本要带画面提示，初稿要结构清楚。

你可以让 千问办公 按你给的模板和选题逐条产出，风格统一、带钩子带 CTA，省掉从零憋稿的痛苦。

**推荐的工作流是：**
1. 提供选题表 \+ 你满意的文案模板
2. 指定形态（口播/图文/软文）、时长或字数
3. 按“钩子—正文—互动”结构逐条产出
4. 落成初稿文件，进入适配环节

## 实战 Prompt

### 按模板和选题批量产文案
```text
以后你做我的短视频文案写手。
文件夹里有两个文件：一个是文案模板，一个是选题表。请按模板的结构，根据选题表里的第 1-5 个选题，各产出一条成品文案，保持模板的开头钩子和结尾 CTA 风格，存成文件。

```

### 选题转口播脚本（带画面提示）
```text
我要做一条 40 秒口播视频，主题【主题】，目标人群【人群】。请按"强钩子（前 3 秒）+ 强情绪（全程）+ 强互动（结尾）"的结构写口播文案，口语化、能直接念，并在每段旁边标注运镜或画面提示。

```

### 仿写对标脚本框
```text
你是抖音运营专家。帮我拆解这条作品【作品链接】的文案逻辑和点火点，然后给出一份可直接套用到我【赛道/产品】的仿写脚本框架，我照着填内容就能拍。

```

# 环节④ 多平台适配：一稿多发与出海本地化
>    

**在流水线中的位置：输入＝环节③的初稿文案 ｜ 输出＝各平台成品文案**（小红书/抖音/公众号/电商/海外），喂给环节⑤封装物料。

同一份内容要在多个平台落地，但每个平台的调性、字数、玩法都不同。

这一步是“分发适配车间”：把一份初稿，一次改写成贴合各平台规范的多版文案；做出海的，还要本地化语气、照顾目标市场口味。

这是流水线里最能省体力的一站：逐个平台手改的活，交给它一次跑完。

**推荐的工作流是：**
1. 提供初稿（或产品资料/官网链接）\+ 目标平台清单
2. 指定每个平台的调性与字数
3. 一次性产出多版文案
4. 出海场景叠加本地化与中外对照，落成文件

## 实战 Prompt

### 一个卖点，多平台一次出
```text
这是我们产品的资料【附件/官网链接】。
请基于核心卖点，一次生成三版文案：
①小红书图文笔记（贴合平台规范、有痛点有种草、配 5 个话题标签）；
②抖音口播脚本（30 秒、有钩子）；
③公众号软文（800 字、标题给 3 个备选）。
三版各自贴合平台调性，存成文件。

```

### 出海 / 本地化文案
```text
根据这份规格书【附件】，帮我写 3 个面向【菲律宾/目标市场】的 TikTok 短视频脚本，要有具体生活场景、不要太复杂，语气贴近当地【年轻女性】用户；再配一段店铺商品详情文案。中英文对照给我。

```

### 把一条初稿适配到指定平台
```text
这是我已经写好的一条初稿【粘贴/附件】。
请把它分别改写成适合【微博/视频号/知乎】的版本：保留核心信息，但调整标题、开头、长度和语气以贴合各平台，差异点帮我简单说明。

```

推荐2个 Skills，方便你快速完成目标。

同时你可以让 AI 直接帮你做「翻译 和 改写」，帮助你调整出海本地化、语气和市场口味。

| Skill | 在本环节怎么用 |
|-----|---------------------|
| `doc-coauthoring` | 多版文案并列成稿、便于对比取用 |
| `agent-browser` | 读官网/参考链接补充卖点 |

## 提效小技巧
1. 把“平台 \+ 字数 \+ 调性”写进约束，省去来回返工
2. 直接复用环节③的初稿，适配才不脱节
3. 出海务必要“中外对照”，方便你校对本地化是否到位

# 环节⑤ 物料封装：图文、海报文案与混剪脚本
>    

**在流水线中的位置：输入＝环节④的成品文案 \+ 产品资料 ｜ 输出＝可发布物料**（图文页、海报文案、混剪脚本清单），直接交付发布。

文案到位后，还要封装成能直接发布或交给设计/剪辑的物料。

这一步把文字“成品化”：整理成多页图文宣传内容、切成适合排版的海报文案、或按模板批量生成混剪脚本。

让 千问办公 把一段文案加一个链接，封装成可落地的物料文件，作图和剪辑接手时一目了然。

**推荐的工作流是：**
1. 给成品文案 \+ 产品资料/链接 \+ 目标客群
2. 指定物料形态（图文页数/海报/混剪脚本）
3. 让它把文案切成便于作图的小段
4. 落成物料文件，交付发布或设计。

## 实战 Prompt

### 图文宣传物料
```text
用这段文案结合这个链接里的介绍【文案 + 链接】，重新整理成一份 8 页左右的抖音图文宣传内容，要抓住【目标客群】的关注、体现用户痛点和产品特点。每页文案简洁、便于后续作图时看清，存成文件。

```

### 营销混剪脚本（批量）
```text
按这个模板脚本，创作一批关于【活动/主题】的营销混剪视频脚本。每个分组要有多条口播文案用于混剪分裂，风格统一、有钩子，输出成可直接拍/剪的清单文件。

```

### 企业宣传册 / 软文物料
```text
读取项目文件夹里所有资料，公司情况参考官网【官网链接】。站在公司角度，为【十周年司庆/某主题】写 5 个宣传主题，每个配一句话亮点和一段 200 字展开，整理成宣传物料文档。

```

3. 复杂方案物料先 `/spec` 或反问澄清，少返工。

# 环节⑥ 数据复盘：让结果回流，反哺下一轮
>    

**在流水线中的位置：输入＝各平台数据导出 ｜ 输出＝复盘结论**，反哺环节①②的情报与选题，让流水线形成闭环。

内容发出去不是终点。

这一站把投放、互动、转化数据收回来，算指标、找异常、出结论，更重要的是，把“哪类内容跑得好”反哺回环节①②，让下一次的选题更准。

把数据文件夹丢给 千问办公，它能直接读表、按你的口径算、做透视、标异常，还能生成一段可直接汇报的说明。

**推荐的工作流是：**
1. 提供数据文件/文件夹 \+ 说明字段口径
2. 指定要算的指标和分组维度
3. 聚合统计、标异常、必要时出图
4. 生成可汇报结论，并提炼“高表现内容特征”回填选题库

## 实战 Prompt

### 投放/账户数据复盘
```text
分析这个账户数据【附件】，把每条素材的展现、消费、点击、点击率、平均点击价格、转化量、转化成本列出来，按消费从大到小排序；标题和视频分开统计。最后用 3-5 句话总结哪类素材好、哪类差，以及下一轮选题该往哪个方向加码。

```

### 异常诊断 \+ 汇报话术
```text
这是【业务/渠道】近半年的运营数据。请：1) 找出异常趋势（重点关注环比变化超过 20% 的指标）；2) 结合其他指标分析可能原因；3) 生成一段 150 字左右、可直接向管理层汇报的情况说明。

```

### 多维度 KPI 达成统计
```text
读取文件夹里的【客资/销售】明细，按【城市 × 渠道】做交叉汇总，计算每个维度的【见面数、签单数、签单率】（口径：签单率 = 合同数 / 到店数），生成透视表，把未达标项单独标出，输出可视化报告。

```

# 写在最后

### 2 个小习惯，让流水线自己跑起来

当这六个环节你都跑顺了，最后一步是“减少重复操作”。两个小习惯能让流水线长期高效运转：
1. **把高频环节设成定时任务。例如将**环节①的每日热点简报、竞品动态盯梢，这类每天都要做的事，把满意的 Prompt 设成每天定点自动跑，到点结果就在你桌面上，无需重复发指令。
2. \*\*把模板和口径沉淀成文件。\*\*爆款公式、文案模板、选题表、数据口径，这些一旦定稿就长期复用。每次让 千问办公 直接读这些文件，产出就能稳定衔接上下游环节。
