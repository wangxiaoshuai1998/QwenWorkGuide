# 实战指南｜图片设计、生成和编辑



本文覆盖**用户的 7 大图像创作使用场景**，你可以直接跳到自己最需要的部分：

和生图软件相比，Design 模式解决的是"用 AI 完成一套专业设计工作流"，而不是仅仅"生成一张图"。
- 符合设计规范：不是"AI帮你画图"，可导入/管理完整设计系统，确保输出符合品牌规范，而非风格不可控
- 资产可复用：导入 Figma 设计系统后，AI 生成的结果遵守已有组件规范
- 可二次编辑：支持精准修改元素，而非只能重新生成 or 局部重绘
- 工作流衔接：设计稿可直接导出到 Code 模式生成前端工程，无需切换工具

# 一、图片编辑与修图

**适用场景**：对已有照片/图片进行修改——人像精修、换脸、去水印、换背景、提升分辨率、批量处理等。这是用户最常见的图片类需求之一。

## 核心使用姿势

图片编辑类需求的核心公式是：**「基于已有图片 \+ 明确修改目标 \+ 效果质量要求」**

| 要素 | 说明 |
|------|------|
| **输入素材** | 上传需要编辑的图片（支持多图参考操作） |
| **修改指令** | 明确说明"改什么，不改什么"——精确到区域、元素、风格 |
| **效果约束** | "自然""无痕""高清""保留原始构图"等质量要求 |

## 推荐 Prompt 写法

### 人像精修
> 按照影楼专业精修人像，高清质感胶片光影，自然磨皮保留皮肤肌理，五官立体精致，肤色通透白皙均匀，光影层次柔和，背景氛围感虚化   

**要点解析**：使用专业修图术语堆叠，明确风格（胶片光影）\+ 质感细节（保留肌理）\+ 效果目标（通透白皙均匀），让 AI 理解修图方向。

### 换背景
> 帮我把照片中人物背景，换成蓝色，要求毫无ps痕迹、不突兀，光影和肤色保持一致   

**要点解析**：指定操作对象\+ 质量要求（无痕、光影一致），让 AI 清楚操作边界。

### 去水印 \+ 超分辨率
> 帮我去掉图片下方水印，并提升到2K分辨率，保持画面清晰锐利   

**要点解析**：多步操作用简洁指令组合，明确位置（下方）和目标参数（2K），避免歧义。

### 批量处理
> 请批量处理这组图片：统一裁切为1:1比例，去除光感和反光，做高清处理，输出分辨率不低于1080p   

**要点解析**：批量需求要明确统一标准（比例、分辨率），列出操作步骤，确保一致性。

## 常见误区
- ❌ "帮我修一下图"——太模糊，AI 不知道修什么
- ❌ 不上传参考图就要求换脸——需要提供素材
- ✅ 始终明确"改什么 \+ 不改什么 \+ 效果标准"

# 二、创意艺术图片生成

**适用场景**：从零开始让 AI 生成创意图片——包括壁纸、插画、节气海报、场景图、艺术画作等。这是最考验 Prompt 描述能力的场景。

## 核心使用姿势

创意生图的核心公式是：**「尺寸/比例 \+ 画面主体 \+ 风格/色调 \+ 氛围/细节」**

| 要素 | 说明与示例 |
|------|---------------|
| **尺寸比例** | 16:9横版 / 9:16竖版 / 1920×1080 / 4K — 先定画布 |
| **画面主体** | 核心描述：人物、场景、事件 — "草原上追逐猴子""步行街逛街的女孩" |
| **风格色调** | 国风/写实/卡通/赛博朋克/胶片 \+ 色彩基调 |
| **细节氛围** | 光影、视角、构图、留白、装饰元素等 |

## 推荐 Prompt 写法

### 通用生图（指定技能调用）
> Use Skill: byted-seedream-image-generate 生成一张1920px×1080px的图片，草原上一个牧羊人骑马追逐羊群，黄昏暖光，写实摄影风格   

**要点解析**：明确调用生图技能 \+ 精确尺寸 \+ 简洁的场景描述 \+ 光线/风格定义，一句话高效传达。



### 节气/节日主题海报
> 生成一张节气夏至的竖版海报，要求：绿色荷叶长在石头边，叶子上有水珠，荷花含苞待放，水面波光粼粼，海报上半部分有留白用于后期加文字，色调清新淡雅   

**要点解析**：主题明确（夏至）\+ 逐元素描述画面内容 \+ 构图规划（留白位置）\+ 色调定义，确保输出可直接使用。



### 国风/艺术风格图
> 新中式国风青绿山水写实风端午节竖版海报，背景为淡绿渐变柔光的青绿山水，搭配亭台楼阁、瀑布、落日与飞鸟，画面层次丰富，远景深邃，近景精细   

**要点解析**：风格高密度描述（新中式\+国风\+青绿山水\+写实），元素组合排列，带空间层次（远/近景），适合需要氛围感的高质量输出。



### 人物场景图
> 生成一张16:9横版图片：女孩在室外步行街逛街，侧着头微笑看向镜头，主观视角（第一人称），温暖的午后光线，浅景深背景虚化   

**要点解析**：比例 \+ 人物动作/表情 \+ 视角（主观）\+ 光线 \+ 景深效果，让画面有"镜头感"。



## 进阶技巧
- **从简到繁**：先用一句话生成初版，再根据结果补充细节迭代
- **留白意识**：如果图片后续要加文字，在 Prompt 中预留空间
- **风格参考**：用"类似 XX 风格"快速定义美学方向

# 三、营销海报与电商设计

**适用场景**：为商业营销生成海报、电商详情页、产品主图、社交媒体封面等。核心在于"平台规格 \+ 商业目的"。

## 核心使用姿势

营销设计的核心公式是：**「平台规格 \+ 商品/主题 \+ 视觉风格 \+ 文案信息 \+ 批量需求」**

| 要素 | 说明与示例 |
|------|---------------|
| **平台规格** | 电商详情页(宽750px) / 小红书封面(3:4) / 抖音(9:16) / 速卖通主图(800×800) |
| **商品/主题** | 产品名称、卖点、促销活动 |
| **视觉风格** | 色调、背景、拍摄角度、商业摄影/扁平插画 |
| **批量需求** | "生成6张""4款不同配色""一套详情页分板块展示" |

## 推荐 Prompt 写法

### 电商详情页
> 请根据以下产品信息，生成展示在详情页中的海报。尺寸为：宽750PX，高度不限制。主色调为白色，每个板块分区展示产品卖点，输出格式为PNG图片   

**要点解析**：标准电商详情页规格(750px宽) \+ 色调 \+ 布局方式（分板块）\+ 输出格式，符合平台上架标准。



### 跨境电商上架图
> 生成6张可以直接上架速卖通的保温杯主图，白色背景，产品居中，多角度展示（正面、侧面、45度角、俯视、手持、场景图），800×800px   

**要点解析**：平台（速卖通）\+ 数量（6张）\+ 产品 \+ 背景（白色）\+ 角度清单 \+ 尺寸，可直接用于店铺上架。

### 小红书/社媒封面
> 帮我设计一个小红书笔记的封面，主题是"高效学习方法"，竖版3:4比例，清新文艺风格，带大标题文字区域，配色用莫兰迪色系   

**要点解析**：平台（小红书）\+ 主题 \+ 比例 \+ 风格 \+ 文字需求 \+ 配色方向，覆盖社媒设计的核心要素。



### 节日/活动海报
> 帮我设计端午节的产品包装展示图。要求商业摄影风格，电商场景背景，粽叶等节日元素点缀装饰，均匀柔光。生成4款不同配色方案，比例16:9   

**要点解析**：节日（端午）\+ 拍摄风格（商业摄影）\+ 场景（电商背景）\+ 元素 \+ 光线 \+ 批量（4款），适合 A/B 测试选择。



## 批量生产技巧
- 需要系列图时，明确"保持风格一致，仅变换角度/颜色/文案"
- 一次说明全部规格（尺寸、格式、数量），减少反复沟通
- 提供品牌色/品牌字体要求，确保系列一致性

# 四、Logo/图标/UI 设计

**适用场景**：设计品牌Logo、应用图标、UI组件、二维码等功能性视觉元素。精确尺寸和透明背景是关键。

## 核心使用姿势

Logo/图标设计的核心公式是：**「精确尺寸 \+ 设计理念/元素 \+ 风格参考 \+ 输出格式」**

## 推荐 Prompt 写法

### 品牌 Logo 设计
> 设计一个Logo，将"琦"和"古"两个字进行创意融合，风格参考苹果公司Logo的简约感，输出PNG透明背景和SVG矢量两个版本   

**要点解析**：设计元素（文字融合）\+ 风格参考（苹果简约）\+ 双格式输出，兼顾创意方向和交付标准。



### 功能图标
> Use Skill: canvas-design 生成一张图片，格式PNG，透明背景，用于商城公告通知的图标，尺寸为130×36px，扁平风格，主色调蓝色   

**要点解析**：调用设计技能 \+ 精确像素尺寸 \+ 透明背景 \+ 用途场景 \+ 风格/配色，适合 UI 嵌入使用。

### UI 组件截图
> 帮我生成一个 AI 悬浮窗的效果图，功能是推荐咖啡和解答咖啡相关问题，包含搜索框、推荐卡片和对话气泡三个区域，圆角设计，浅色背景   

**要点解析**：组件名称 \+ 功能描述 \+ 具体区域结构 \+ 视觉风格，输出可作为产品原型参考。

## 关键提醒
- Logo 设计务必说明"透明背景"需求，避免后续抠图
- 图标类需求必须给精确像素尺寸（如 64×64、128×128）
- 有品牌参考时提供品牌名或上传参考图，效果更精准

# 五、图表与流程图制作

**适用场景**：生成流程图、架构图、思维导图、组织结构图等信息可视化图表。适合项目汇报、技术文档、业务梳理。

## 核心使用姿势

图表制作的核心公式是：**「图表类型 \+ 节点/层级内容 \+ 格式要求」**

## 推荐 Prompt 写法

### 业务流程图
> 帮我绘制一张从上到下的业务流程图：顶层"用户注册" → 中层"身份验证"（分支：成功/失败） → 下层"进入主页/返回登录"，使用SVG格式输出   

**要点解析**：明确布局方向（从上到下）\+ 节点名称 \+ 逻辑关系（分支）\+ 输出格式。



### 参考图复刻
> 请按照我上传的图片所示的布局和配色，结合以下文档内容，生成一份类似风格的项目管理流程示意图   

**要点解析**：上传参考图 \+ 提供内容数据 \+ 要求"类似风格"，让 AI 同时理解形式和内容。

### 架构图
> 绘制一张系统架构图，分为三层：前端层（React \+ Next.js）、服务层（Node.js \+ Python）、数据层（MySQL \+ Redis \+ ES），用箭头标注调用关系   

**要点解析**：分层结构 \+ 技术栈 \+ 关系标注，适合技术文档使用。

# 六、IP角色与动漫创作

**适用场景**：设计原创IP角色、动漫形象、表情包、角色三视图等。从简单单角色到完整IP体系均可覆盖。

## 核心使用姿势

IP角色设计的核心公式是：**「角色特征 \+ 画风指定 \+ 展示方式 \+ 用途」**

## 推荐 Prompt 写法

### 角色三视图（专业级）
> 蘑菇拟人角色标准三视图：正面、侧面、背面，水平并列排布。全身展示，三个视角人物比例一致，Q版卡通风格，大眼圆脸，穿红色波点连衣裙，白色纯背景   

**要点解析**：标准角色设计规范（三视图）\+ 排布方式 \+ 比例一致性要求 \+ 风格 \+ 服装描述 \+ 背景要求，可直接用于后续建模或表情包制作。



### 简单角色生成
> 画一条12岁的害羞的美人鱼女孩，二次元风格，半身特写，粉紫色调，精致大眼，尾巴鳞片有珍珠光泽   

**要点解析**：角色（美人鱼女孩）\+ 性格（害羞）\+ 画风（二次元）\+ 构图（半身）\+ 色调 \+ 质感细节。



### IP \+ 文化融合
> 设计一个江西油纸伞非遗主题IP形象，紧扣国潮与非遗主题，角色头部以油纸伞为灵感，服装融入传统纹样，色彩使用中国红\+金色，Q版比例（头身比2:1）   

**要点解析**：IP定位（非遗）\+ 文化元素来源 \+ 设计规范（头身比）\+ 色彩体系，适合商业IP开发。

# 七、产品与工业设计

**适用场景**：产品外观设计、3D建模、包装设计、工程图纸等专业领域。需要精确参数和专业术语。

## 核心使用姿势

产品/工业设计的核心公式是：**「精确尺寸参数 \+ 材质/工艺 \+ 迭代方向 \+ 图纸类型」**

## 推荐 Prompt 写法

### 产品建模
> 帮我生成一个现代简约风格沙发的效果图，尺寸为长3.2米、宽2米、高0.5米（座面）和0.55米（靠背），灰色织物面料，实木腿，45度俯视角   

**要点解析**：精确尺寸（到小数点）\+ 风格 \+ 材质描述 \+ 视角指定，适合产品方案展示。



### 工业设计迭代
> 这是一款卫星对讲机的ID效果图，请在原图基础上优化细节：不调整尺寸和布局，仅修改配色（改为深空灰\+橙色点缀）、增加机身纹理、优化按键手感区域的凹凸设计   

**要点解析**：基于已有设计迭代 \+ 明确边界（不改尺寸布局）\+ 精确优化方向（配色/纹理/按键），适合设计评审后的修改。

### 工程图纸
> 参考上传的设计方案，按建筑制图规范绘制：1:100平面图、1:50剖面图、1:20节点详图，标注尺寸和材料说明   

**要点解析**：图纸类型 \+ 比例尺 \+ 规范要求 \+ 标注内容，符合工程出图标准。

# 八、通用技巧与最佳实践

**掌握以下通用原则，适用于所有图像创作场景：**

## Prompt 结构化公式

| 顺序 | 要素 | 作用 |
|------|------|------|
| 1 | **尺寸/比例** | 确定画布——16:9 / 9:16 / 1920×1080 / 750px宽 |
| 2 | **主体内容** | 画面核心——人物、物品、场景 |
| 3 | **风格/色调** | 美学定位——写实/插画/国风/赛博朋克 |
| 4 | **细节/约束** | 补充信息——光线、视角、构图、留白、文字区域 |
| 5 | **输出要求** | 交付标准——格式(PNG/SVG)、透明背景、数量 |

## 效率倍增建议

**推荐做法：**
- 先定尺寸再描述内容
- 复杂需求分步拆解
- 提供参考图 \+ 文字说明
- 批量需求一次说清规格
- 使用 Use Skill 调用专用技能

**避免做法：**
- "帮我画个图"——过于模糊
- 一次提多个互相矛盾的要求
- 不提供参考就要求"和某某一样"
- 忽略输出格式和尺寸
- 描述过于抽象无法视觉化

## Skill 技能调用速查

| 技能 | 适用场景 |
|------|------------|
| `byted-seedream-image-generate` | 通用图片生成（风景、人物、创意图） |
| `byted-seedance-video-generate` | 视频生成（短视频、动画片段） |
| `canvas-design` | 设计类图片（海报、图标、UI组件） |
| `pencil` | Logo 和矢量图设计 |
>    

**小贴士**：不确定用哪个技能时，直接用自然语言描述需求，AI会自动选择最合适的能力执行！
