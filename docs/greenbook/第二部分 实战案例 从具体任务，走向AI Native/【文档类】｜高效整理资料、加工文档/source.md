资料整理与文档加工，几乎是每个岗位每天都在做的事，本文覆盖用户的 7 大使用场景，你可以直接跳到自己最需要的部分：

| 场景 | 帮你做什么 | 匹配的用户需求 | 典型诉求 |
|------|---------------|---------------------|------------|

| 场景三 | 资料汇总与结构化整理 | 多来源材料归并成一份完整文档 | "把这些零散材料汇总成一份结构清晰的文档" |

## 七大场景实战介绍

### 场景一 · 文档读取理解与分析

把一摞资料、一个网页或一篇长文档读懂，并给出可用的结论——这是最高频的需求，难点在于输入量大、来源分散、读完还要交叉核对。给 千问Work 投喂时直接拖文件或贴链接即可，不用复制正文；它能一次读多份材料并跨文件对照，找出冲突、缺漏和重复，最后把结论落成你要的形态。

🔧 **推荐工作流**：① 投喂来源（拖文件 / 贴网页或钉钉/飞书链接）→ ② 说清要哪种产出（综述 / 要点清单 / 核对报告，给谁看）→ ③ 让它跨多份材料交叉核对冲突与缺漏 → ④ 落盘成 Word / Markdown 或写入钉钉/飞书文档。

常用搭配：doc-coauthoring（组织长文）、agent-browser（抓网页）、data-analysis（表格资料聚合）、飞书 MCP/钉钉DWS（读写云文档）。

#### 常用 Skills

| Skill | 在本场景怎么用 |
|-----|---------------------|
| doc-coauthoring | 把读完的结论组织成综述、要点清单等长文，结构清晰 |
| agent-browser | 抓取网页 / 竞品官网 / 在线资料，直接读取后再分析 |
| data-analysis | 读 Excel / 表格类资料，做归类、汇总、交叉核对 |
| 飞书 MCP/钉钉DWS | 读取飞书/钉钉云文档 / 知识库作为来源，或把结论写回飞书/钉钉 |

#### 典型用法

这个场景里最常见的三类活，写 Prompt 时把它们说清楚就行：
- **多文档归纳成结构化对比**：把若干份资料按统一维度拉成一张表，一眼看清异同。适合读论文、读竞品、读多份方案。
- **长文档提炼关键信息**：从几十页的合同、政策、报告里只摘你关心的那几类条款或结论，标注出处方便回溯。
- **交叉核实一致性**：让它对照原始材料逐项核对某份文档里的数据 / 表述是否准确，把不一致处单独列出来。

#### 实战 Prompt

**联网读竞品并出调研综述**
> 全面读取这两个网址 https://A.com 和 https://B.com，从"目标用户、核心功能、定价、差异化卖点"四个角度整理对比，输出一篇图文清晰的调研综述 Word，结论部分给出 3 个可借鉴的点。   

**多份材料按维度整理成对比表**
> 读取我上传的 5 份资料，按"核心观点 / 方法或做法 / 关键数据 / 结论 / 局限"五个维度整理成一张对比表；再单独列出哪些内容被多份材料重复提到，标注各自出处。输出为 Word 保存到本地。   

**长文档只提取我关心的条款**
> 通读这份 40 页的【合作协议 / 政策文件】，只提取与【付款、违约、保密、终止】相关的条款，逐条列出"所在条款号 / 原文摘要 / 通俗解读"，整理成一张可快速过目的清单。   

**交叉核实数据是否一致**
> 这份【申报书 / 汇报材料】是基于附件里的原始数据整理的。请逐项核实其中的关键数字与原始材料是否一致，不一致处用表格列出"文档表述 / 原始数据 / 差异"，并提示可能的风险点。   

✅ **提效要点**：① 先说清"给谁看、要多详细"，它才会把握综述的深浅；② 要求"标注出处 / 条款号"，结论可回溯、好抽检；③ 材料超多时让它先列大纲再展开，避免遗漏。

### 场景二 · 排版格式与模板套用

按模板或格式要求重排文档、统一字体样式、批量替换数据并保持格式——这是最"体力活"的场景，也最能省时间。关键在于把"格式要求"和"待处理稿件"一起交给它：它能直接在文件上改并导出新版，原稿保留；改完还能告诉你动了哪些地方，方便抽检。

🔧 **推荐工作流**：① 同时提供模板 / 格式要求（图或文档）和原稿 → ② 圈定改动范围（只动格式不动内容 / 只改指定段落）→ ③ 让它执行并写回新文件 → ④ 要求列出改动点，你抽检。

常用搭配：docx 处理能力（读写 Word 保留样式）、brainstorming（复杂格式规则先澄清）、飞书 MCP/钉钉DWS（套用云文档模板）。

#### 常用 Skills

| Skill | 在本场景怎么用 |
|-----|---------------------|
| docx / 文档处理能力 | 读写 Word 并保留样式，按模板 / 规范重排后导出新文件 |
| brainstorming | 格式规则复杂或描述不清时，先和它对齐排版要求再执行 |
| 飞书 MCP/钉钉DWS | 套用飞书云文档模板、把排好版的内容写入云文档 |

#### 典型用法
- **套用现成模板**：把你的内容灌进一个模板（学校论文模板、红头文件、报告模板），样式跟着模板走，内容不动。
- **批量统一格式**：一个文件夹里十几份格式各异的文档，一次性统一成同一套样式，逐个另存、原文件保留。
- **按格式规范重排**：没有模板、但有一套格式要求（期刊投稿规范、公司文档标准），让它逐条对齐字号、行距、标题层级、参考文献样式。

#### 实战 Prompt

**按格式要求重排（内容一字不改）**
> 第一个 Word 是我的稿件，第二张图是目标【期刊 / 单位】的格式要求。请严格按要求排版：标题层级、正文字号行距、图表标题、参考文献样式都要符合，正文内容一个字都不要改，输出为新 Word，原稿保留。   

**批量统一一个文件夹的格式**
> 这个文件夹里有 8 份文档，格式各不相同。请统一成：一级标题黑体三号、正文宋体小四、行距 1.5、每份首行加文档名称。逐个处理后另存到 output 目录，原文件别动，并列出每份做了哪些调整。   

**参照往期格式做定期汇总**
> 按我前两期的格式整理本期【周报 / 简报】：先读取"【行业资讯】"知识库，再从【指定来源】摘取与【主题】相关、相关性高的内容，按上期的栏目结构汇总，每条配一句话点评。   

**跨表替换数据并保持模板样式**
> 把"原始台账"里【工程部位、数量、编号、日期】等列的数据，按行对应替换到"模板"的相应字段，替换后这些单元格内容居中、保持模板原有边框和底色，生成新文件。   

**把内容灌进现成模板**
> 按这份模板，把我的初稿内容填进去：封面 / 抬头信息我标在文末，标题、摘要、目录、章节都用模板的样式，生成新文件。   

✅ **提效要点**：① 明确说"只改格式、不动内容"或"只改某几段"，避免误伤；② 模板用图片给它也能识别，但用 Word 模板效果更稳；③ 一定要它"另存新文件、保留原稿"，留好回退余地。

### 场景三 · 资料汇总与结构化整理

把多个来源（文件 / 笔记 / 网页 / 知识库）汇总归类，产出一份完整材料。这类需求往往是多步骤工程：要读、要筛、要去重、要按统一结构重组。建议先用 /plan 让它列出"读取 → 筛选 → 归类 → 生成"的计划，确认后再执行，避免跑偏；大材料让它分章节产出，借助记忆保持前后口径一致。

🔧 **推荐工作流**：① 输入 /plan 让它先拆解步骤并列计划 → ② 指定来源与口径（读哪个知识库 / 按什么主题筛 / 保留哪些维度）→ ③ 大材料按章节分段产出，借助记忆保持前后一致 → ④ 导出 Markdown / Word 便于后续复用。

常用搭配：/plan 工作流、agent-browser（联网搜集）、chart-visualization（汇总后出图）、知识库 / 飞书 MCP/钉钉DWS/钉钉DWS

#### 常用 Skills

| Skill | 在本场景怎么用 |
|-----|---------------------|
| /plan 工作流 | 多步骤汇总先让它出"读取 → 筛选 → 归类 → 生成"计划，确认再跑 |
| agent-browser | 联网搜集资料、去重，再按你的结构重新整理 |
| chart-visualization | 汇总出数据后顺手出图，让材料更直观 |
| 知识库  | 读取知识库 / 云文档作为来源 |

#### 典型用法
- **多份零散材料整合成一份**：把数据表、记录、截图、笔记等不同形态的材料，归并成一份结构清晰的文档。
- **联网搜集 \+ 重新组织**：让它上网找资料、去重后按你给的结构重新整理成系统材料。
- **多份文件归并统一**：把若干份各自独立的文件合成一本，统一章节编号、措辞风格，自动生成目录。

#### 实战 Prompt

**多份零散材料整合成一份**
> 这是某项工作的 5 份零散材料（数据表、记录、截图、预算表、群聊导出）。请整合成一份文档，包含"目标达成 / 亮点 / 问题 / 下一步"四部分，数据用表格呈现，来源在文末统一标注。   

**联网搜集再重新整理（先 /plan）**
> /plan 使用 agent-browser，在网上为我找至少 10 份高质量的【主题】资料，去重后按"【维度一 / 维度二 / 维度三 / 实战】"重新整理成一份系统文档，每节附带要点和推荐延伸阅读，数据标明来源。   

**多份文件归并成一本**
> 把这【6】份分散的【制度 / 讲义 / 方案】整合成一本《【名称】》，统一章节编号和措辞风格，目录自动生成，不要丢失关键定义和数据，输出 Word。   

✅ **提效要点**：① 多步骤任务先 /plan 看它的计划，确认无误再放手跑；② 给它一份"往期样例"，比口头描述格式更准；③ 明确"按什么筛、保留哪些维度"，避免它贪多塞进无关内容。

### 场景四 · 文档对比审阅与校对

同时读多个版本，自动找差异、查重、纠错、做审阅。把多份文件一起交给它，让差异以"位置 \+ 原文 \+ 建议改法"的表格呈现，确认后再写回新文件、保留原稿。它的优势是能逐字对照、不漏改动，还能归纳出对方主要关注的几类问题。

🔧 **推荐工作流**：① 同时投喂多个版本 → ② 明确比对维度（内容差异 / 查重 / 纠错 / 一致性）→ ③ 要求结构化输出修订表 → ④ 复核后写回新文件。

常用搭配：docx / pdf 处理能力（跨格式读多版本）、doc-coauthoring（审阅意见成稿）、飞书 MCP/钉钉DWS（结论写入云文档协同）。

#### 常用 Skills

| Skill | 在本场景怎么用 |
|-----|---------------------|
| docx / pdf 处理能力 | 跨格式读取多个版本，逐字对照找差异、查重、校对 |
| doc-coauthoring | 把审阅意见、修订建议组织成规范的修订表 / 审阅稿 |
| 飞书 MCP/钉钉DWS | 把对比结论写入飞书云文档，方便多人协同复核 |

#### 典型用法
- **新旧版本比差异**：对比两版文档，找出实质性改动（金额、期限、责任、表述），逐条标注并提示风险。
- **查重 \+ 校对**：检查重复 / 高度相似段落，以及错别字、标点、数字错误，给出位置和修正建议。
- **对照修改稿**：把初稿和改后稿放一起，列出改了哪些地方，并归纳对方主要关注什么。
- **多份核对一致性**：同一信息在多个文档 / 台账 / 凭证里是否对得上，把对不上的条目挑出来。

#### 实战 Prompt

**新旧版本逐条比差异**
> 对比新旧两版【合同 / 方案】，找出条款层面的实质性改动（金额、期限、责任主体、关键表述），逐条标注"条款号或位置 / 旧表述 / 新表述 / 潜在风险"，汇总成审阅表，重点风险用醒目方式标出。   

**查重 \+ 校对（不改原意）**
> 检查这篇【论文 / 稿件】是否有重复或高度相似的段落，以及错别字、标点和数字错误，列出位置和修正建议，不要改动我的原意和专业表述。   

**对照修改稿、归纳关注点**
> 文件 1 是我的初稿，文件 2 是【对方 / 导师 / 领导】返回的修改版。请逐条列出改了哪些地方（位置 \+ 原文 \+ 改后），并归纳出他主要关注的几类问题，方便我后续自查。   

**两份核对一致性**
> 把这份【台账 / A 版】和【凭证清单 / B 版】对比，逐条核对【金额、日期 / 数据、表述】是否一致，列出对不上的条目，并指出哪一份更可能准确。   

**双文档对比成表**
> 第一个文件是【要求 / 标准】，第二个文件是【我的实际情况 / 现状】。请对比后生成表格，逐项给出"已有 / 要求 / 缺口"，并把还差的关键项单独列出来。   

✅ **提效要点**：① 一次只问一类对比（先比差异、再查重），结果更聚焦；② 要求"结构化成修订表"，比一段话描述好复核；③ 强调"不改原意 / 先出建议我确认"，避免它擅自落笔。

### 场景五 · 表格制作与数据整理

从文档 / PDF 中提取信息成表、补全字段、生成对比表，或对表格数据做聚合统计。说清要提取哪些字段、按什么维度组织，让它直接产出可用的表格并标注缺口项。它不仅能"提取成表"，还能做求和、交叉汇总、多表关联这类计算活，省去你手工搬数据。

🔧 **推荐工作流**：① 给出原始资料和目标表头 → ② 指定提取 / 对比 / 聚合口径 → ③ 生成表格并标注缺口（Word / Excel / 飞书表格）→ ④ 让它说明数据来源行便于抽检。

常用搭配：data-analysis（查询、聚合、多表关联）、chart-visualization（整理后出图）、飞书 MCP/钉钉DWS（写入多维表格 / 电子表格）。

#### 常用 Skills

| Skill | 在本场景怎么用 |
|-----|---------------------|
| data-analysis | 提取字段成表、查询、求和、交叉汇总、多表关联统计 |
| chart-visualization | 表格整理好后顺手出图（占比、趋势、对比） |
| 飞书 MCP/钉钉DWS | 把结果写入飞书多维表格 / 电子表格，便于后续协作 |

#### 典型用法
- **多份文档提取成对比表**：从多份 PDF / Word 里抽出指定字段，拼成一张对比表，缺失项标出来。
- **提取 \+ 聚合统计**：读明细做交叉汇总、求和、透视，或把两张表按某个 ID 关联后再统计。
- **非结构化转结构化**：把一段格式很乱的文本（群聊报名、零散记录）整理成规范表格。

#### 实战 Prompt

**多份文档提取成对比表**
> 从这几份【报价单 / 简历 / 方案】PDF 里提取"【字段一、字段二、字段三……】"，整理成一张对比表，同一对象的不同来源并排放，【最低价 / 关键项】用标注突出，缺失项标"待补"。   

**提取 \+ 聚合统计**
> 读取这几个月的【报销 / 销售】明细 Excel，按"【部门 × 类别】"做交叉汇总求和，生成一张透视表，并标出【超预算 / 异常】的项，附一句简短说明。   

**多表关联再统计**
> 把"【A 表】"和"【B 表】"按【共同字段 ID】关联，统计每个【对象】的【总金额、笔数】，按金额降序输出成表，前 10 名标为重点。   

**乱文本转规范表格**
> 这是一段【群里收集的报名 / 零散登记】信息，格式很乱。请提取每条记录的"【姓名、电话、单位、场次……】"整理成规范表格，缺失项标"待补"。   

✅ **提效要点**：① 先把"目标表头"列清楚，它照着填最准；② 要做计算时说明口径（按什么分组、求和还是计数）；③ 让它"标注数据来自原文哪一行"，方便核对、不怕算错。

### 场景六 · 格式转换与文件生成

PDF / 图片 / 视频 / 网页 转成 Markdown / Word，或按模板从零生成新文档，并直接落盘或上传飞书。说清从什么转成什么、存到哪、是否保真即可；转换失败它会自动重试修复，批量任务也能跑。这一步常常是前面几个场景的"出口"——整理好的内容，到这里变成你要的最终文件。

🔧 **推荐工作流**：① 给出源文件和目标格式、保存位置 → ② 明确保真要求（原文不动 / 重新排版 / 存多份）→ ③ 执行转换或生成并落盘，必要时上传飞书 → ④ 失败自动重试直到产出可用文件。

常用搭配：docx / pdf 处理能力、/spec 或 brainstorming（从零生成前对齐结构）、飞书 MCP/钉钉DWS（上传云空间 / 写入云文档）。

#### 常用 Skills

| Skill | 在本场景怎么用 |
|-----|---------------------|
| docx / pdf 处理能力 | 在 Word / PDF / Markdown 之间转换，保真或重排都行 |
| /spec 或 brainstorming | 从零生成文档前先对齐章节结构和要求，少返工 |
| 飞书 MCP/钉钉DWS | 把生成的文件上传飞书云空间，或直接写入云文档 |

#### 典型用法
- **批量格式转换**：一个文件夹的文件统一转格式，失败的单独列清单。
- **网页 / 文章转文档归档**：把一篇在线内容原样存成 Word / Markdown，顺手上传飞书/钉钉。
- **按要求从零生成**：给一份"要求 \+ 参考格式"，让它生成结构完整的新文档。
- **图片 / 音视频转文字**：识别图片里的文字结构、把视频音频转成可读文字稿。

#### 实战 Prompt

**批量转换格式**
> 把这个文件夹里所有 PDF 转成 Markdown，文件名保持一致，统一存到 output 子目录；转换失败的单独列一个清单告诉我。   

**网页 / 文章转 Word 并归档**
> 把这篇文章原文不动地写入 Word 并导出到本地；同时另存一份 Markdown，上传到飞书/钉钉"我的文件夹"，文件名用文章标题。   

**按要求从零生成文档**
> 请按这份 PDF 里的要求，参照第二个 Word 的格式风格，生成一份结构完整的【报告 / 方案】，章节需包含【背景 / 分析 / 方案 / 风险 / 预算】，保存为新文件。   

**图片信息转规范文档**
> 这几张是【手写草图 / 拍照的资料】照片，请识别其中的文字和结构，整理成一份规范的【需求说明 / 纪要】Word，分点列出，看不清的地方标"待确认"。   

**音视频转文字稿**
> 把这个【视频 / 录音】转成文字稿，按发言顺序分段，去掉口头语，整理成可阅读的图文纪要，导出 Word。   

✅ **提效要点**：① 说清"保真还是重排"——存档要原样、给人看可重排；② 批量任务让它"失败的单独列清单"，一眼看到漏网的；③ 从零生成前给一份参考样例，风格更贴近你的预期。

### 场景七 ·钉钉/飞书文档读写与云端协作

直接把飞书/钉钉云文档、知识库、电子表格、多维表格当作"来源"读进来分析，也能把整理、汇总、转换后的成果一键写回飞书/钉钉云文档或多维表格——无需手动复制粘贴、导出再上传。这是"资料整理与文档加工"这一大类的独特优势：整条链路可以在你团队已有的飞书/钉钉空间里闭环完成，前面六个场景的成果，到这里都能直接落在飞书里。

🔧 **推荐工作流**：① 给出飞书/钉钉文档 / 表格 / 知识库链接作为来源 → ② 说清要读什么、做什么分析或整理 → ③ 指定写回目标（新建云文档 / 写入已有文档 / 多维表格）→ ④ 执行并回链，结果直接出现在飞书里。

常用搭配：飞书 MCP/钉钉DWS（云文档 / 电子表格 / 多维表格读写）、docx / markdown 处理、/spec（写回前对齐结构）。

#### 常用 Skills

| Skill | 在本场景怎么用 |
|-----|---------------------|
| 飞书 MCP/钉钉DWS（云文档） | 读取、创建、编辑飞书/钉钉云文档，按 block 精准插入与替换 |
| 飞书 MCP/钉钉DWS（电子表格 / 多维表格） | 读写 Sheet 与 Base 数据，做聚合统计、多表关联、批量更新 |
| 飞书 MCP/钉钉DWS（知识库 / 云空间） | 在知识库里定位文档、把文件上传到云空间 |
| docx / markdown 处理 | 本地文件与飞书/钉钉文档之间互转，保持层级和格式 |

#### 典型用法
- **读飞书文档做分析**：把一篇 / 一批飞书/钉钉云文档读进来，提炼要点、交叉核对结论。
- **汇总写回云文档**：把多份材料汇总成一份结构清晰的飞书/钉钉文档，直接生成在指定空间。
- **本地与飞书/钉钉互通**：把本地整理好的内容一键写入飞书/钉钉文档，或把飞书/钉钉内容导出到本地。
- **表格数据处理**：读多维表格 / 电子表格做聚合统计，结果写回新表或原表。

#### 实战 Prompt

**读飞书文档提炼摘要**
> 把这几篇飞书/钉钉文档【贴链接】读完，提炼核心结论和关键数据，交叉核对有没有冲突，整理成一份摘要，新建一篇飞书云文档存到【空间 / 文件夹】。   

**多来源汇总并写回飞书/钉钉**
> 把这些飞书/钉钉文档和本地材料汇总成一份结构清晰的【周报 / 方案】，按【章节】组织，直接生成在飞书云文档里，给我回链。   

**本地内容写入飞书/钉钉文档**
> 把这份本地 Markdown 的内容按原结构写入飞书/钉钉云文档【链接或新建】，标题用【xx】，保持层级、表格和代码块格式不变。   

**多维表格统计回写**
> 读这张多维表格【链接】，按【字段】分组统计【指标】，把结果写回一张新表，并在原表加一列【标记】。   

**飞书表格转图文文档**
> 把这张飞书/钉钉电子表格里的数据整理成一份图文说明文档，关键数字做成表格，写入飞书/钉钉云文档。   

✅ **提效要点**：① 来源和写回目标都贴链接最稳，省去它找文件的时间；② 写回前说清"新建还是写入已有"，避免覆盖原文；③ 大批量读写可以让它先列清单再执行，方便核对。

### 3 个让结果更好的小习惯
- **圈定边界**："只动格式 / 旧文件别动 / 只改某段"，一句话约束能避免误伤，省去返工。
- **复杂任务先 /plan**：多步骤的活先让它出计划、你确认再执行，过程可控、结果更稳。
- **说清产出形态**：明确是要文件还是文字、什么格式、存到哪——这样它才会真正帮你落盘，而不是只回一段话。

### Skills 怎么用？一分钟扫盲
- Skill（技能）是 内置的一组专项能力，比如处理 Word、PDF、Excel，或读写飞书文档。
- 你不用记命令，绝大多数时候直接用大白话说需求，它会自动判断该用哪个 Skill——例如你说"把这个 PDF 转成 Word"，它就自动调用 PDF / Word 处理能力。
- 想手动指定也可以：在输入框打 / 会弹出技能列表，选一个（如 /spec）即可；带 / 的就是需要这样唤起的命令式技能。下面每个场景的"常用 Skills"表，只是告诉你这件事大概会用到哪些能力，照着写需求就行，不用自己去配置。
