# 实战指南｜Excel 表格数据处理

在日常工作中，Excel 几乎是每个职场人都离不开的数据工具。

无论是整理销售报表、核对财务账目、统计人员信息，还是分析项目进度、制作月度汇报，数据分析的需求无处不在。

但面对复杂的公式、重复的手工操作和海量的原始数据，很多人会感到力不从心。千问办公 的 AI 能力，正是为了帮你在这些场景中大幅提效。
> 本文覆盖职场 Excel 用户的 7 个核心使用场景，你可以直接跳到自己最需要的部分：   

| **场景** | **适合** |
|----------|----------|
| **场景一：数据清洗与格式整理** | 乱糟糟的原始数据、格式不统一、重复值、空格问题 |
| **场景二：表格生成与模板创建** | 需要快速搭建标准表格、批量生成结构化数据表 |
| **场景三：数据查询与筛选提取** | 从大表里找特定数据、多条件筛选、跨表匹配 |
| **场景四：数据计算与公式生成** | 复杂公式不会写、批量计算、统计汇总 |
| **场景五：表格修改与内容更新** | 批量修改单元格、条件更新、数据补全 |
| **场景六：数据分析与报表制作** | 透视表、图表、趋势分析、周报月报自动化 |
| **场景七：高效技巧与 Prompt 写法** | 让 AI 更懂你的 Excel 需求 |

## 场景一｜数据清洗与格式整理

原始数据总是"脏"的——多余空格、格式不统一、重复值、日期格式混乱……手动清洗费时费力。千问办公 可以帮你把"脏数据"一键变成"干净数据"，让后续分析不再被格式问题卡住。

**4 步搞定数据清洗：**
1. **上传原始数据** — 将需要清洗的 Excel/CSV 文件放入 Workspace，支持同时上传多个文件进行跨表清洗
2. **描述清洗需求** — 用自然语言告诉 AI 需要处理哪些问题：去重、去空格、统一日期格式、拆分合并单元格等
3. **AI 执行清洗** — 自动按照你的要求处理数据，支持多文件协同清洗、跨表匹配核对
4. **结果校验与导出** — AI 自动进行一致性检查，输出清洗后的可编辑 Excel 文件，并标注修改记录

### 案例演示

#### **Prompt 1 — 数据清洗（带数据验证）**
```Plain
请帮我深度清洗以下销售数据表格，完成后需要：
1. 统一日期格式为 YYYY-MM-DD
2. 统一金额为数字格式（保留两位小数）
3. 删除重复记录，并告知删除了哪些行
4. 统一姓名格式
5. 修正所有错别字
6. 对空值行用"待补充"标记
7. 新增一列"数据质量评分"（A/B/C三档），评估每条记录的数据完整性
8. 输出清洗报告：统计各类问题数量、清洗前后对比

```



#### **Prompt 2—跨表格数据整理**
```Plain
我有两份数据：① 序时账.xls ② 银行流水.xlsx。请帮我完成数据清洗：
统一两份数据的日期格式（YYYY-MM-DD）和金额格式（保留2位小数）；
按'同一银行账号 + 相同金额 + 日期相差不超过3天'的规则自动匹配核对；
输出清洗后的核对结果表，并标注未匹配的记录。

```

## 场景二｜表格生成与模板创建

需要快速搭建一个标准表格？或者根据业务需求批量生成结构化数据表？千问办公 支持基于业务背景和列结构描述，自动生成符合规范的 Excel 模板。

**3 步搞定表格生成：**
1. **描述业务背景** — 告诉 AI 表格的用途、业务场景
2. **设计结构** — 用自然语言描述需要的**行/列名**和每行/列的**数据类型**，或上传**参考模板**让 AI 模仿格式
3. **生成并导出** — AI 自动生成标准 Excel 文件，支持复杂表头、合并单元格、格式规范

### 案例演示

#### **Prompt 1 — 模板生成：**
```Plain
请帮我创建一个项目进度跟踪表模板，包含以下列：
项目编号、项目名称、负责人、所属部门、开始日期、结束日期、项目状态、进度(%)、优先级、预算(元)、已用预算(元)、风险等级、备注

要求：
1. 项目状态设置下拉选项：未开始/进行中/已暂停/已完成/已取消
2. 优先级设置下拉选项：高/中/低
3. 风险等级设置下拉选项：高/中/低
4. 进度列设置数据验证：0-100
5. 新增"预算执行率"列，用公式计算：已用预算/预算
6. 预留10行空白行供填写

```



#### **Prompt 2 — 业务模板定制：**
```Plain
我需要为不同部门创建定制化的项目跟踪模板。请基于通用项目跟踪表，生成三个部门定制版本：

1. 【IT部版本】增加字段：技术栈、系统模块、测试状态、上线日期；技术相关项目需要额外审批标记
2. 【市场部版本】增加字段：活动类型、目标受众、预计触达人数、实际触达人数、ROI
3. 【财务部版本】增加字段：费用类型、审批人、报销状态、凭证编号、合规检查

每个版本都保留通用字段和智能功能（下拉、条件格式、公式），并预填2-3条示例数据。

```

## 场景三｜数据查询与筛选提取

从几千行数据里找出符合条件的记录？用正则表达式提取特定格式的信息？跨表匹配查找对应值？千问办公 支持用自然语言描述查询条件，自动完成复杂的数据筛选和提取任务。

**3 步搞定数据查询：**
1. **明确数据源** — 告诉 AI 要查询哪个文件的哪一列/哪一行，支持同时指定多个查询范围
2. **描述查询条件** — 用自然语言说明筛选规则，支持正则表达式、多条件组合、跨表匹配
3. **输出查询结果** — AI 自动执行查询，将匹配结果输出到指定位置，支持高亮标注匹配行

### **案例演示**

#### **Prompt 1 — 基础筛选：**
```Plain
请帮我从以下员工信息表中筛选数据：
1. 找出所有"技术部"中薪资大于20000元的在职员工
2. 找出2023年1月1日之后入职的所有员工
3. 找出上海和杭州两地的所有员工
4. 找出学历为"硕士"或"博士"的员工

每个查询结果单独输出为表格，并统计人数。

```



#### **Prompt 2 — 统计汇总查询：**
```Plain
请基于以下员工信息表，生成一份人力资源统计报表：

1. 【部门统计】各部门人数、平均薪资、最高/最低薪资
2. 【城市分布】各城市员工人数、薪资中位数
3. 【学历分析】各学历等级的人数和平均薪资
4. 【入职年份分析】按入职年份统计人数，计算各年留存率
5. 【在职状态】在职/试用期/离职人数及占比
6. 【TOP5薪资】列出薪资最高的5位员工（含部门、职位、城市信息）

报表需要包含数据表格和简要分析文字。

```

## 场景四｜数据计算与公式生成

复杂的嵌套公式不会写？需要统计某个条件下的汇总值？千问办公 支持用自然语言描述计算逻辑，AI 自动生成正确的 Excel 公式，甚至直接帮你算出结果。

**4 步搞定公式生成与计算：**
1. **描述计算目标** — 用自然语言告诉 AI 你想算什么，比如"统计同一个报销点编码使用同一个实际分摊比例超过7次的清单"
2. **指定数据范围** — 告诉 AI 涉及哪些文件的哪些单元格/列，支持跨文件、跨 Sheet 计算
3. **生成公式或直接计算** — AI 自动生成对应公式（如 VLOOKUP、SUMIFS、COUNTIFS 等），或直接执行计算输出结果
4. **验证与解释** — AI 对生成的公式进行逻辑解释，并帮你验证计算结果的正确性

**进阶技巧：**   对于复杂的多层级验证场景（如财务对账），可以让 AI 同时生成多个验证公式，进行交叉校验，确保数据一致性。

### 案例演示

#### **Prompt 1 — 分类汇总公式：**
```Plain
请帮我基于以下费用明细表，使用公式完成以下计算：

1. 按费用类别汇总总金额（使用SUMIF）
2. 按部门汇总总费用并排名（使用SUMIF + RANK）
3. 统计各支付方式的费用笔数和总金额
4. 计算每笔费用的预算执行率（金额/预算额度），超标标红

输出包含公式的完整表格和汇总结果。

```

#### **Prompt 2 — 综合计算报表：**
```Plain
请基于费用明细表生成一份完整的费用分析计算报表：

【汇总区】
1. 总费用、总预算、预算执行率
2. 超标笔数、超标总金额、超标率

【分类分析】
3. 各类别费用汇总（SUMIF）
4. 各类别平均单笔费用
5. 各类别费用占比（公式计算）

【趋势分析】
6. 月度费用趋势（按月SUMIF）
7. 月度环比增长率

【TOP分析】
8. 金额最大的5笔费用（LARGE + INDEX/MATCH）
9. 超标金额最大的3笔费用

【公式说明】
10. 列出所有使用的公式及其功能说明

请输出完整的分析报表。

```

## 场景五｜表格修改与内容更新

需要**批量修改**某些符合条件的单元格？更新数据后要保证格式不变？千问办公 支持基于条件精准修改表格内容，并自动进行质量校验，避免手动修改带来的错误风险。

**4 步搞定表格修改：**
1. **指定目标文件与范围** — 明确告诉 AI 要修改哪个文件的哪个 Sheet、哪些行/列，支持条件筛选（如"仅修改 C 列为 none 的行"）
2. **描述修改规则** — 用自然语言说明修改逻辑，支持条件判断、批量替换、格式调整
3. **执行修改并标注** — AI 自动执行修改，可按你的要求对修改过的单元格进行高亮标注，方便人工复核
4. **二次校验** — AI 自动对修改后的结果进行一致性检查，确保修改符合预期，并输出校验报告

⚠️ **安全提示：**   对于重要数据文件，建议**先保存副本**。如果选择让 AI 直接在文档内修改，建议**先"预览"修改结果，确认无误后再执行写入**。也可以要求 AI 对修改内容进行黄色高亮标注，方便你逐一复核。

### **案例演示**

#### **Prompt 1 — 批量修改：**
```Plain
请帮我修改以下产品库存表：

1. 将所有"网络设备"类别的产品单价上调5%，同步更新库存总值
2. 将供应商"联想集团"批量替换为"联想（北京）有限公司"
3. 将缺货产品（库存=0）的安全库存上调50%
4. 根据当前库存数量重新计算所有产品的库存状态：
   - 库存=0 → "缺货"
   - 库存 < 安全库存 → "库存不足"
   - 库存 >= 安全库存 → "正常"

输出修改后的完整表格，并标注修改了哪些行。

```



#### **Prompt 2 — 安全修改（带校验）：**
```Plain
请帮我安全地更新产品库存表，每次修改后需要进行数据校验：

【第一步：价格更新】
- 所有"电源设备"类别单价下调3%
- 所有"配件"类别单价上调2%
- 校验：确认单价均为正数，库存总值=库存数量×单价

【第二步：供应商统一】
- "思科系统" → "思科系统（中国）有限公司"
- "华为技术" → "华为技术有限公司"
- 校验：确认无供应商名称为空的记录

【第三步：状态重算】
- 重新计算所有产品的库存状态
- 校验：确认状态与库存数量/安全库存的关系正确

【第四步：异常检测】
- 标记库存数量为负数的记录
- 标记单价异常高（>50000）或异常低（<50）的记录
- 标记安全库存>库存数量3倍的产品

每步输出修改内容 + 校验结果，最后输出最终表格。

```

## 场景六｜数据分析与报表制作

透视表不会做？图表不知道选哪种？周报月报每次都要手动填？千问办公 支持基于你的数据自动生成透视表、推荐合适图表、并将分析结果按模板格式输出为标准化报表。

**4 步搞定数据分析与报表：**

**上传数据源** — 将需要分析的数据文件（Excel/CSV）放入 Workspace，支持多文件联合分析

**描述分析目标** — 告诉 AI 你想从数据中看出什么：趋势、对比、占比、异常值等

**生成分析与图表** — AI 自动生成透视表、推荐合适图表类型（柱状图/折线图/热力图等），并将分析结果输出为结构化报告

**填入报表模板** — 如果你有固定的报表格式（如周报模板），可以让 AI 直接将分析结果填入对应位置，实现报表自动化

### 案例演示

#### **Prompt 1 — 多维度分析：**
```Plain
请基于全年区域销售业绩数据，完成以下多维度分析：

【维度一：区域 × 产品线交叉分析】
1. 生成 7区域 × 5产品线 的销售额交叉表
2. 找出每个区域的最强产品线和最弱产品线
3. 找出每个产品线表现最好的区域

【维度二：利润率分析】
4. 计算各区域的利润率（利润/销售额），排名
5. 计算各产品线的利润率，排名
6. 找出利润率最高和最低的月份-区域-产品线组合

【维度三：客户分析】
7. 各区域客户数和平均客单价对比
8. 客户数增长趋势（按季度）
9. 销售员人均产出排名（按区域）

输出完整分析报表。

```



#### **Prompt 2 — 综合管理报表：**
```Plain
请基于全年区域销售业绩数据，生成一份年度销售管理报表，包含以下板块：

【一、执行摘要】
- 全年总销售额、总成本、总利润、利润率
- 同比/环比关键指标变化
- 核心发现（3条）

【二、区域分析】
- 各区域销售额排名（表格+排名图描述）
- 各区域利润率对比
- 区域增长趋势（Q1-Q4季度对比）

【三、产品线分析】
- 产品线销售额占比
- 产品线利润贡献排名
- 产品线季节性特征分析

【四、运营效率】
- 客单价变化趋势
- 人均产出分析
- 订单转化效率

【五、TOP/BOTTOM分析】
- TOP10：销售额最高的月份-区域-产品线组合
- BOTTOM5：表现最差的组合
- 增长最快TOP5 vs 下降最快TOP5

【六、Q4预测】
- 基于前9个月数据，预测Q4各区域销售额
- 预测方法说明

【七、行动建议】
- 3条可执行的业务优化建议

报表需格式化输出，每个板块包含数据表格 + 分析文字。

```

#### **Prompt 3 — 调用技能生成分析图表：**
```Plain
请调用 data-analysis 技能，基于全年区域销售业绩数据完成以下分析并输出可视化图表：

1. 各区域销售额占比（饼图）
2. 全年销售额趋势（折线图）
3. 区域 × 产品线销售额热力图
4. 输出每张图表的解读说明

```

通过这种方式，你可以直接复用 千问办公 内置的数据分析技能，无需从零写 Prompt，也能获得标准化的分析流程和输出格式。

## 更多技巧：让 AI 更懂你的 Excel 需求

掌握以下技巧，让 TAE Work 的 Excel 处理能力更上一层楼。

**技巧一：提供清晰的数据源定位**   告诉 AI 越多文件细节，输出质量越高。比如不要只说"帮我统计这个表"，而要说清"统计'销售数据.xlsx'中 Sheet1 的 B 列到 F 列，按 A 列的客户名称分组汇总"。

**技巧二：善用多文件协同**   千问办公 支持同时处理多个 Excel 文件。你可以将需要核对的多个文件一起上传，让 AI 自动完成跨表匹配、差异对比、合并汇总等复杂任务。

**技巧三：明确输出格式要求**   在办公场景中，格式规范很重要。告诉 AI 你需要的输出格式：可编辑的 Excel 文件、带格式的报表、高亮标注的修改记录等，AI 会严格按照你的要求输出。

**技巧四：利用技能提升效率**   千问办公 内置了丰富的数据处理技能，覆盖数据清洗、公式生成、报表制作等常用场景。对于高频需求，你还可以让 AI 帮你创建自定义技能——比如一个「财务对账」技能，设定好匹配规则和输出格式后，每次只需上传两份数据文件即可自动生成核对结果。

**技巧五：让 AI 解释公式逻辑**   不只是生成公式，千问办公 还能解释公式的计算逻辑。当你拿到一个复杂公式不知道它在算什么时，让 AI 帮你"翻译"成自然语言，帮你真正理解而不是盲目套用。

| **添加或创建** | 方法一：TRAE 技能市场内置了数据分析、Excel 处理等领域的优质技能，你可以直接添加后运行。 <br>方法二：如果你获取到了某个 .skill 文件，也可以直接导入使用。 <br>方法三：告诉 千问办公 你的需求，让 AI 帮你创建自定义技能。 |

### Excel 场景常用 Skill 推荐

| **Skill 名称** | **适合场景** | **能力示例** | **安装方式** |
|----------------|----------------|----------------|----------------|
| chart-visualization | 根据用户的数据，自动选择最合适的图表，并生成可视化结果。 | **分析数据**：识别数据类型（时间、分类、占比、关系、地图等）。  <br>**智能选图**：自动选择最适合的图表（如折线图、柱状图、饼图、散点图、思维导图等）。   <br>**生成图表**：将数据转换成图表，并调用生成工具输出图片。   <br>**返回结果**：提供图表图片链接，以及生成图表所使用的配置参数。 | TAE Work 内置 |
| consulting-analysis | 咨询级研究报告生成器 | **搭建研究框架**：根据研究主题（如市场、行业、品牌、消费者、金融等），自动设计分析框架、章节结构、分析模型、数据需求和图表规划。  <br>**生成专业报告**：结合收集到的数据，将分析结果整理成咨询公司（如麦肯锡、BCG）风格的 Markdown 报告。   <br>**保证数据可信**：所有结论和图表必须基于真实提供的数据，不允许编造或推测。   <br>**提供可视化与洞察**：自动规划并嵌入图表，通过“数据 → 原因 → 策略建议”的逻辑输出有深度的分析。 | TAE Work 内置 |
| data-analysis | 用户上传的 Excel 或 CSV 文件进行快速查询、统计分析和结果导出。 | **解析数据结构**：自动识别工作表、字段、数据类型、行数等信息。  <br>**SQL 数据分析**：支持使用 SQL 对数据进行筛选、聚合、排序、关联查询等分析。   <br>**统计汇总**：自动生成均值、中位数、标准差、分位数、缺失值等统计指标。   <br>**导出分析结果**：支持将查询结果导出为 CSV、JSON 或 Markdown 格式。   <br>**高性能处理大数据**：基于 DuckDB，可高效分析大型 Excel/CSV 文件，并支持多文件、多工作表联合分析。 | TAE Work 内置 |
