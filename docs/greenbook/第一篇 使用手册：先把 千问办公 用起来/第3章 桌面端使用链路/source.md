<span style="color: rgb(73, 70, 65);">从下载到第一个任务交付，5 分钟体验完整流程。</span>

<span style="color: rgb(73, 70, 65);">QwenWork 是一款本地运行的桌面应用，更像一位真正能"把活干完"的 AI 队友，而不只是聊天工具。这篇指南会带你走完一遍完整流程：下载安装、登录账号、熟悉工作界面，最后亲手提交第一个任务。</span>

<span style="color: rgb(73, 70, 65);">读完这一页，你的电脑上会有一个可用的 QwenWork、一个登录好的账户，以及一项正在本地运行的真实任务。</span>

## <span style="color: rgb(24, 24, 27);">**1\. 下载 QwenWork**</span>

<span style="color: rgb(73, 70, 65);">访问官网下载页</span>  [qwenwork.cn/download](https://qwenwork.cn/docs/getting-started/qwenwork.cn/download)<span style="color: rgb(73, 70, 65);">，点击对应你系统的 macOS 或 Windows 按钮下载安装包。</span>

<span style="color: rgb(73, 70, 65);">目前支持两个平台：</span>
- <span style="color: rgb(73, 70, 65);">macOS 14 及以上，同时兼容 Apple Silicon 和 Intel 芯片。</span>
- <span style="color: rgb(73, 70, 65);">Windows 10 及以上，仅 64 位版本。</span>

<span style="color: rgb(73, 70, 65);">请确认磁盘空间至少 500 MB，并保持网络稳定——QwenWork 在使用过程中会从云端拉取模型、技能与连接器。</span>

### <span style="color: rgb(24, 24, 27);">**macOS**</span>

<span style="color: rgb(73, 70, 65);">下载完成后，双击</span>  `.dmg`  <span style="color: rgb(73, 70, 65);">文件，将 QwenWork 图标拖入 Applications 文件夹。等待拷贝结束后弹出磁盘映像，然后从启动台或</span>  `/Applications/QwenWork.app`  <span style="color: rgb(73, 70, 65);">启动应用。</span>

<span style="color: rgb(73, 70, 65);">首次启动时，Gatekeeper 可能会拦截并提示</span>  <span style="color: rgb(73, 70, 65);">*"*</span><span style="color: rgb(73, 70, 65);">无法打开 QwenWork.app，因为 Apple 无法检查其是否包含恶意软件</span><span style="color: rgb(73, 70, 65);">*"*</span><span style="color: rgb(73, 70, 65);">。打开 系统设置 → 隐私与安全性，下拉到底部找到 QwenWork 对应的提示，点击 仍然打开 即可。这一步只会出现一次。</span>

### <span style="color: rgb(24, 24, 27);">**Windows**</span>

<span style="color: rgb(73, 70, 65);">运行</span>  `.exe`  <span style="color: rgb(73, 70, 65);">安装包，按默认选项一路下一步即可。安装完成后，可以在开始菜单和桌面找到 QwenWork 的快捷方式。</span>

<span style="color: rgb(73, 70, 65);">如果 Windows Defender SmartScreen 弹出"Windows 已保护你的电脑"提示，点击 更多信息 → 仍要运行 即可继续安装。</span>

## <span style="color: rgb(24, 24, 27);">**2\. 登录账号**</span>

<span style="color: rgb(73, 70, 65);">首次启动 QwenWork 时，会出现欢迎页提示你登录。左侧是 登录/注册 按钮、语言切换，以及用于配置代理的 网络设置 入口；右侧展示产品标语。</span>

### <span style="color: rgb(24, 24, 27);">**按下回车之后会发生什么**</span>

<span style="color: rgb(73, 70, 65);">澄清问题（视情况而定）</span>

<span style="color: rgb(73, 70, 65);">遇到复杂或不够明确的需求时，QwenWork 不会立刻动手，而是先抛出一两个澄清问题，例如：</span><span style="color: rgb(73, 70, 65);">*"是否需要把其他同类开源产品也包含进来？""价格用美元还是本地货币？"*</span>  <span style="color: rgb(73, 70, 65);">先花十几秒澄清，能省掉之后大段的返工。直接在同一个对话里回答即可，回复送达后任务正式开始。如果需求本身已经足够清晰，这一步会自动跳过。</span>

<span style="color: rgb(73, 70, 65);">任务监控</span>

<span style="color: rgb(73, 70, 65);">任务执行过程中，工作区会一分为二：左侧仍是对话，展示 AI 的解释和阶段性回复；右侧的 任务监控 会实时显示真正的执行内容——任务计划、产物、当下使用的 技能 & MCP 服务。</span>

![](https://alidocs2.oss-cn-zhangjiakou.aliyuncs.com/res/WgZOZA5GYaAw8qLX/img/16a060a4-ea4c-4d59-980e-2e7e9fb33b08.webp?Expires=1785258863&OSSAccessKeyId=LTAI5tKTjg4Kq1HCdBJ8qpSp&Signature=S2Bm9k0QPk%2FiH82Xt5ynHgLHnJs%3D "")

<span style="color: rgb(161, 157, 150); background-color: rgb(248, 248, 247);">image.png</span>

<span style="color: rgb(73, 70, 65);">一切都是透明的——你看到的不只是答案，而是 QwenWork 是怎么得到这个答案的。如果中途发现方向不对，直接在对话里追加一句话即可——它会排入队列，等当前这一轮结束后接着执行，QwenWork 会保留完整上下文，不必从头再来。</span>

<span style="color: rgb(73, 70, 65);">收取产物</span>

<span style="color: rgb(73, 70, 65);">任务结束后，QwenWork 会同时给你两件东西：一段在对话里的总结，说明它都做了什么；以及一个或多个 产物——具体的可下载文件，比如这次要的 Excel 表格。产物是真实的本地文件，直接创建并保存在你电脑上，可随时打开、编辑或转移。</span>

<span style="color: rgb(73, 70, 65);">点击产物卡片可以直接预览或下载。产物会一直附着在这个任务上，之后从侧边栏的 任务 能找回来。</span>

<span style="color: rgb(73, 70, 65);">对结果不满意？不用重来，直接在同一个对话里继续说就行。比如 "按价格从低到高排序" 或 "再加一列免费版的额度限制"。QwenWork 会基于完整的任务上下文继续修改产物，迭代效率非常高。</span>
