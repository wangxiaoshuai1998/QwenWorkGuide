# **系统设置**

QwenWork 所有设置项总览：偏好、个人资料、系统、语音、快捷键、工作台、安全与实验特性

## **通用**

### **偏好设置**

个性化界面外观与对话体验：

| <span style="color: rgb(39, 42, 38); background-color: rgb(245, 247, 243);">**设置项**</span> | <span style="color: rgb(39, 42, 38); background-color: rgb(245, 247, 243);">**说明**</span> |

| 语言 | 选择界面语言（中文 / English ），修改后立即切换 |
| 主题亮暗 | 亮色、暗色或自动（跟随系统） |

### **个人资料**

管理头像与账户信息（头像、账号与订阅信息）：
- 头像——可自定义背景色（11 种颜色可选）与图标（用户名首字符或 Emoji）。
- 账户UID——显示当前账户的专属用户标识，仅供查看和复制。
- 订阅——显示当前账户的套餐，点击「查看套餐与定价」跳转套餐页。
- 退出登录——在此设备退出登录，可随时重新登录。

### **语音输入**

全局语音输入快捷键与转录设置（详见  [语音输入](https://qwenwork.cn/docs/features/voice-input)）：
- 启用语音输入——启用全局语音输入快捷键。按一次开始录音，再按一次停止并转录。
- 快捷键模式——选择如何触发语音录制：单按键，或组合键（如 Ctrl\+Shift\+Space）。
- 触发按键——所选按键仅在单独按下时触发语音输入，正常组合键操作不受影响。

捕获最前方应用的截图与可读文本，作为对话上下文（详见  [应用快照](https://qwenwork.cn/docs/desktop/app-snapshots)）：
- 全局快捷键——在此选择触发方式（如同时按下左右两个 Option 键）。

### **更新应用**

检查并获取 QwenWork 新版本，与菜单栏中的「检查更新」一致。有新版本时会弹出提示，确认后才会下载并重启更新；已是最新版本时会直接显示「当前已是最新版」。

### **已归档**

归档任务的集中管理页。每条归档任务可单独恢复或彻底删除，也可点击右上角「全部删除」一次清空。

## **高级设置**

### **安全工作环境**

在你的电脑上单独开辟一块独立空间来跑任务——执行更快、更稳定，所有文件和数据都不会离开你的设备：
- 启用安全工作环境——开启后，任务会在隔离的工作环境中运行，不影响你电脑上的其他文件，也不会触及真实系统。
- 清理工作环境文件，释放磁盘空间——会删除已下载的工作环境文件，但不会删除你的对话记录和工作产物。
